# Vasilyev Karate Club — промо-сайт (SPA)

Одностраничный промо-сайт карате-клуба **Vasilyev Karate Club** (Рига, с 1984 года): 11 секций, тексты на трёх языках (RU/EN/LV), лёгкая 3D-сцена в Hero, скролл-анимации GSAP и встроенная лента Facebook.

## Стек

- **React 19 + Vite 8 + TypeScript**
- **Tailwind CSS v4** (utility-first, тема в `src/index.css`)
- **GSAP + ScrollTrigger** — вход секций, счётчики (уважает `prefers-reduced-motion`)
- **Three.js** — лёгкий фон Hero (динамический импорт, отдельный чанк)
- **lucide-react** — иконки (брендовые Facebook/Instagram — свои SVG в `src/components/icons.tsx`)

## Быстрый старт

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # tsc -b && vite build (прод-сборка в dist/)
npm run preview  # предпросмотр прод-сборки
```

  i18n.tsx              # контекст языка + переключатель

    Section (обёртка + заголовки), SmartImage (фото с фолбэком), icons (SVG соцсетей)

## Где менять контент

Всё — в **`src/content.ts`**: каждое текстовое поле имеет вид `{ ru, en, lv }`. Разделы соответствуют ТЗ (`vasilyev-karate-landing.md`).

## Что осталось заполнить (плейсхолдеры)

- **Расписание** тренировок по залам (`content.halls`) — сейчас примерные дни/время.
- **Цены** — сейчас «цена по телефону» (без фиксированных сумм, как просил владелец). Вернуть конкретные € можно в `content.pricing.groups` (`price: number | null`) — тогда в карточке группы вместо строки «Цена по телефону» появится сумма.
- **Группы обучения** (`content.pricing.groups`) — карточки собраны по возрасту и аудитории (4-6, 7-12, подростки и взрослые). Название, описание, ритм занятий и пункты меняются там же; новая группа — новый объект в массиве.
- **Email** клуба (`content.contacts.email` = `null`).
- **Достижения** (`content.achievements`) — наполнить из Facebook-ленты клуба.
- **Логотип** — положить файл в `public/logo.png` — автоматически появится в шапке и подвале (пока показывается запасной знак 拳).
- **Фото залов** — положить в `public/images/halls/ikskiles.jpg` и `public/images/halls/latgales.jpg` (пока аккуратная заглушка).
- **Новости в «Жизни клуба»** — настроить токен Facebook и запустить `npm run sync:fb` (см. раздел «Жизнь клуба: посты из Facebook»).
- **Форма заявки** — код готов, осталось получить бесплатный ключ Web3Forms и вписать его в `content.form.accessKey` (пошаговая инструкция ниже, раздел «Форма заявок: Web3Forms»). Ключ можно выпустить на свой email и позже перевыпустить на ящик клуба — сам код при этом не меняется.
- **Реальные посты** в «Жизни клуба» — появляются автоматически после синхронизации; демо-карточки просто перестают показываться.
- **Домен** — заменить `https://vasilyev-karate.lv` (canonical, OG-теги, sitemap, robots), см. раздел «SEO и локальный поиск».

## Форма заявок: Web3Forms (установка)

Статичный сайт сам письма не отправляет: нужен посредник. Используем **Web3Forms** — бесплатный релей «заявка → письмо на почту». Free-план: **250 заявок в месяц, без карты, бессрочно** (для клуба это ~8 заявок в день с запасом).

> Почему не EmailOctopus: их формы работают только как JS-вставка (`eocampaign1.com/form/xxx.js`), готовой точки приёма для своей формы у них нет, и письмо о новой заявке по умолчанию не приходит (в их же справке предложено настраивать Make). Это ещё и рассылочный сервис — каждая заявка стала бы подписчиком списка.

**Что нужно сделать (1 раз):**

1. Открыть https://web3forms.com и указать **email, куда должны приходить заявки** (ящик клуба, или сначала свой — письма приходят именно на этот адрес).
2. Подтвердить адрес по ссылке из письма — в ответ придёт **Access Key** (UUID вида `a1b2c3d4-5e6f-4a7b-8c9d-0e1f2a3b4c5d`).
3. Вписать ключ в `src/content.ts`, в `content.form.accessKey` (сейчас `null`):
   ```ts
   accessKey: 'a1b2c3d4-5e6f-4a7b-8c9d-0e1f2a3b4c5d',
   ```
4. (Рекомендуется) задать `content.contacts.email` — адрес клуба: появится в секции «Контакты» и станет фолбэком отправки.
5. Проверить: `npm run dev`, заполнить форму на сайте и убедиться, что письмо пришло. Сменить ящик позже = выпустить новый ключ и заменить строку — код не меняется.

**Как это работает в коде** (`src/components/Contacts.tsx`):
- если `accessKey` задан — `POST https://api.web3forms.com/submit` (JSON); в письме приходят поля `name`, `phone`, `age`, `comment`, `lang` и `utm` (источник заявки: utm_source/gclid/fbclid);
- если ключа нет, но задан `contacts.email` — фолбэк: открывается почтовый клиент посетителя (mailto);
- если ничего не настроено — форма показывает ошибку с телефоном клуба.

Ключ Web3Forms **не секретный**: он лежит в коде страницы и лишь адресует заявку на ваш ящик (то же и у сервисов-аналогов). Никаких приватных ключей в проекте хранить не нужно.

**Защита от спама.** В форме есть скрытое поле `botcheck` (honeypot): люди его не видят, боты отмечают — такие заявки сервис отбрасывает.

## Быстрые способы связи помимо формы

- **WhatsApp** — открывает чат с уже готовым текстом («Здравствуйте! Хочу записаться на бесплатную пробную тренировку»). Кнопка есть в трёх местах: в первом экране рядом с «Записаться», в каждой карточке группы (в текст добавляется название группы: «… (Дети 7-12 лет)») и рядом с телефонами в контактах. Ничего настраивать не нужно, но номер задаётся в `content.contacts.whatsapp` — на нём должен быть активен WhatsApp. Ссылки собирает `src/lib/whatsapp.ts`.
  - На телефоне подписи кнопок короткие (`hero.cta2Short`, `contacts.whatsappLabelShort`), чтобы три кнопки влезали в две строки и первый экран не удлинялся.
- **Звонок** — телефоны в шапке, в карточках групп и в контактах.

Оба канала не зависят от формы: даже без ключа Web3Forms посетитель может написать или позвонить.

## Жизнь клуба: посты из Facebook

Секция показывает реальные посты страницы клуба - без iframe и сторонних виджетов. Один пост = одна карточка: фото, описание, дата, ссылка «Смотреть в Facebook». Текст публикуется как есть (без переводов) - так, как клуб написал.

**Как это работает**

- `npm run sync:fb` забирает последние 12 постов через Facebook Graph API, скачивает фото в `public/images/posts/` и генерирует `src/data/facebookPosts.ts`.
- `ClubLife` берёт данные из этого файла; если он пуст (токен ещё не настроен), показываются демо-карточки из `content.social.posts`.
- Фото хранятся локально намеренно: ссылки Facebook CDN со временем протухают, а локальные файлы работают всегда и быстро.

**Настройка токена (один раз)**

1. developers.facebook.com → My Apps → Create App (тип Business).
2. Graph API Explorer: выбрать приложение и страницу клуба, выдать права `pages_show_list` и `pages_read_engagement`, скопировать Page Access Token (в Access Token Debugger можно продлить его до долгоживущего).
3. Создать в корне `.env.local` (файл уже в `.gitignore`, токен в репозиторий не попадёт):
   ```
   FB_PAGE_ID=...
   FB_PAGE_TOKEN=...
   ```
4. `npm run sync:fb` → затем обычный `npm run build` и деплой.

**Автообновление новостей.** Запускать `npm run sync:fb` перед деплоем, либо поставить cron в CI (например, GitHub Actions - раз в сутки), который синхронизирует посты, коммитит `src/data/facebookPosts.ts` и фото, после чего сайт пересобирается. Если нужен полностью «живой» фид без пересборки - потребуется маленькая серверлесс-функция с кэшем (токен остаётся на сервере); текущая схема выбрана, чтобы не тащить бэкенд и не платить за него.
## SEO и локальный поиск

Настроено: `title`/`description`, canonical, Open Graph (ru/en/lv), Twitter-карточка, JSON-LD `SportsClub` (два зала с адресами и картами, соцсети, 1984, карате) и `WebSite`, `public/robots.txt`, `public/sitemap.xml`, `public/site.webmanifest`, SEO-блок `SeoBlock` перед контактами с текстом про карате в Риге и Кенгарагсе.

**Перед публикацией на реальном домене:** заменить `https://vasilyev-karate.lv` в `index.html` (canonical, og:url, og:image, JSON-LD), в `public/robots.txt` и `public/sitemap.xml`. Иконка уже оптимизирована: `public/favicon.png` - 512×512, 169 КБ вместо исходных 573 КБ (прозрачность сохранена). Сильнее сжать можно только в WebP (~43 КБ), но это потребует менять ссылки на иконку и лишит поддержки `apple-touch-icon` в старых Safari. Язык по умолчанию для поисковиков - русский (то, что лежит в `index.html`); переключатель RU/EN/LV работает на клиенте.

## Рекламный трафик (Meta Ads / Google Ads)

Готовые якоря для объявлений: `#hero` (первый экран), `#kids` (детские группы), `#programs` (все группы), `#halls` (залы и расписание), `#contacts` (форма заявки).

Примеры ссылок:
- пробное занятие: `https://vasilyev-karate.lv/?utm_source=facebook&utm_medium=cpc&utm_campaign=trial#contacts`
- детское карате: `https://vasilyev-karate.lv/?utm_source=google&utm_medium=cpc&utm_campaign=kids#kids`
- залы: `https://vasilyev-karate.lv/?utm_source=facebook&utm_medium=cpc&utm_campaign=halls#halls`

`utm_source/medium/campaign/content/term`, а также `gclid` и `fbclid` сохраняются в `sessionStorage` (`src/lib/utm.ts`) и уходят вместе с заявкой в поле `utm` - видно, какая кампания принесла заявку. Meta Pixel и GA4 намеренно не подключены (приватность); при необходимости добавляются отдельным скриптом.

## Будущие идеи (не в MVP, архитектура готова)

### Клубный мерч

Модели описаны в `src/types.ts` (закомментированный блок): `Product { id, slug, name, description, images, price, sizes?, active, order }` и `MerchOrder { name, phone, email?, productId, size?, qty, delivery: 'pickup-cash' | 'shipping' | 'payment-link', address?, comment, createdAt, status }`. Заявку можно отправлять тем же способом, что и форму записи (Web3Forms / mailto), позже - в Strapi. Компоненты на будущее: `MerchSection`, `ProductCard`, `OrderForm`; место в навигации зарезервировано после FAQ (пункт меню пока не показываем, чтобы не вести в пустоту).

### Баннеры и попап-баннер

Модели `Banner { placement, image, imageAlt, title?, ctaLabel?, ctaLink?, activeFrom?, activeTo?, isActive, priority }` и `PopupBanner { ...те же..., description?, displayDelay }` - тоже описаны в `types.ts`. Логика попапа на будущее: страница грузится как обычно, затем через `displayDelay` мс показывается модалка с картинкой, alt, заголовком, текстом, кнопкой CTA и крестиком в правом верхнем углу; одновременно активен только один баннер (выбирается по `priority` внутри окна `activeFrom`/`activeTo`), закрытие запоминается в `localStorage`, есть закрытие по Escape и клику по фону. Компоненты на будущее: `PromoBanner`, `PopupBanner`. Готовая инфраструктура - `SmartImage` (картинка + fallback) и `content`-структура.
